How I use AI

I use coding agents, mostly Claude Code, for a lot of my daily work. Here is how I keep their changes easy to check.

A written spec before any code

On my last team, every ticket in the Android repo got a spec first, covering what we found, the plan, and an approval. Then the agent wrote failing tests, and only after that the code to make them pass. If an existing test broke, it stopped and told me instead of editing the test.

Reviewing pull requests

I have the agent check a pull request against the ticket's spec and the team's checklist. For example: is there an approval, and what does the screen do offline? I still read the diff myself.

Firebase and Jira in the agent

Crashlytics, Remote Config, and Jira are connected to the agent through MCP. I can look at a crash, find the cause in the code, and update the ticket without switching between tools.

Trying tools before recommending them

Before I suggest a new AI tool to a team, I set it up myself. When I tried a self-hosted agent platform, I found a bug that broke its documented no-login mode and wrote a small workaround. I recommended a security review before using it on company code.
